CSS:
-> a stylesheet language used to apply styles to html elements
-> allows to control the layout, colors, fonts and overall visual appearance of a webpage without altering the html structure
-> the primary purpose of CSS is to separate the presentation of a document from its content
-> contributes to responsive web design by allowing adjustments to layout and styling based on device screen size
-> the cascading nature of CSS means it allows styles to be inherited or overridden in a hierarchical manner

CSS Rule:
-> made up of two main parts - selector and declaration block
-> selector { poperty: value }
-> a selector is a pattern to identify and target specific html elements
-> type selector, class selector, id selector

Viewport:
-> <meta name="viewport"> gives instructions to browsers on how to control the page's dimensions and scaling on different devices
-> width=device-width tells the browser to match the page width to the device's screen width

Default Browser Styles / User-Agent Styles:
-> provides basic formatting to ensure html elements are displayed in a readable way across all browsers

Width and Height:
-> controls the dimensions of an element on a webpage
-> can be defined in px, %, vw, vh and more
-> if you do not specify the width and height, they will be set to auto
-> it lets the browser determine the element's width and height based on its content, parent and display type
-> for a div, width: auto makes it expand to fill the full width of its parent container

Pixel:
-> fixed size unit of measurement
-> provides precise control over dimension

Combinators:
-> defines the relationship between selectors
-> help select elements based on their relationship to other elements
-> allows for more precise and efficient styling
-> descendant combinator (space), child combinator (>), next-sibling combinator (+), subsequent-sibling combinator (~)

Block Elements:
-> take up the full width available to them
-> stretch across the width of their container
-> start on a new line and push other contents to the next line
-> div, p, headings, ol, ul, section
-> sizes can be controlled

Inline Elements:
-> take up as much width as they need
-> do not start on a new line
-> flow within the content
-> sizes cannot be controlled
-> span, a, img

Inline-block Elements:
-> remain in the text flow without starting on a new line
-> sizes can be adjusted

Margin:
-> controls the space outside an element
-> helps define the layout structure and separate from other elements

Padding:
-> controls the space inside an element
-> improves content readability and aesthetic appeal

Specificity:
-> determines which styles are applied to an element when rules could apply
-> calculated based on the type of selectors used
-> highest: inline style applied through style attribute
-> next, id selectors
-> next, class selectors, attribute selectors and pseudo classes
-> next, type selectors and pseudo elements

Universal Selector (*):
-> matches any element in the document
-> lowest specificity

important Keyword
-> !important
-> gives a style rule the highest priority, overriding any other declarations for a property
-> used after the css value and before the semicolon

Cascading Algorithm:
-> the process browser uses to decide which css rules to apply when there are multiple styles targeting the same element
-> ensures that most appropriate styles are used based on  a set of well defined rules
-> begins with relevance
-> then considers origin and importance
-> next looks at specificity
-> finally order of appearance comes into play

Inheritance:
-> color, font-family, line-height are inherited by default
-> margin, padding, border, background are not inherited by default
-> if you want a child element to inherit these styles, you need to use inherit keyword

Link States:
-> link, visited, hover, focus, active

Pseudo Class:
-> a keyword added to a selector that specifies a special state of that element

Background Image:
-> background-size, background-repeat, background-position, background-attachment
-> background: center top fixed url("")

Gradient:
-> a smooth transition between two or more colors
-> linear gradient and radial gradient
-> linear gradient transitions color along a straight line
-> background: linear-gradient(direction, color-stop1, color-stop2, ...)
-> linear-gradient(to right, red, yellow)
-> radial gradient transitions colors from an origin (usually the center) outward in a circular or elliptical shape
-> background: radial-gradient(shape size at position, color-stop1, color-stop2, ...)
-> radial-gradient(circle closest-side at corner, red, yellow 50%, green)

Absolute Units:
-> fixed-size unit of measurement. not relative to anything else
-> pixel (px)
-> 1 pixel = 1/96 inch
-> use when you need precise control over element dimensions, spacing, and layout

Percentages:
-> a relative unit that allow yous to define sizes, dimensions and other properties as a proportion of their parent element
-> it essentially means, make this X% of its container
-> ideal for creating fluid layouts that adapt to different screen sizes
-> using for flexible images is another common practice
-> less common but can also be used for font sizes to create scalable typography
-> particularly handy for vertical centering


em:
-> relative unit
-> relative to the font size of the element
-> if you use em for font-size property, the size of text will be relative to the font size of parent element
-> good to use when you're working with modular components like buttons or cards
-> it can ensure that all aspects of the component such as padding, margin, border scale proportionally with font size


rem:
-> unit for typography
-> relative to the font size of the root element which is html
-> by default, font size of html element is 16px
-> preferred over pixel for typography as it scales proportionally with the user's browser setting
-> can also help maintain consistent spacing and layout across different elements


vh:
-> viewport height
-> 1vh is equal to 1% of the viewport's height

vw:
-> viewport width
-> 1vw is equal to 1% of the viewport's width

# vh and vw are relative units that allow you to size elements based on the dimension of the browser window
# useful when you want to create full-screen layouts or elements that maintain a specific proportion of the screen



Pseudo Classes:
-> special keywords that allow you to select an element based on its specific state or position. It includes:
-> when its active
-> when its being hovered over by a mouse
-> when its the first child of a parent
-> when its the last child of a parent
-> when a link has been visited
-> when its disabled
-> to use, you add it to the selector by using a colon followed by the name of the pseudo class
-> active, hover, first-child, last-child, visited, disabled, focus, first-of-type, last-of-type, nth-of-type, 
   modal, enabled, checked, required

Action Pseudo Classes:
-> special keywords that allow you to provide feedback without needing javascript or any programming language
-> hover, active, focus, visited, focus-within, enabled, disabled, target


Input Pseudo Classes:
-> used to make forms more intuitive and user-friendly
-> focus, hover, checked, required, valid, invalid, disabled, autofill, optional, in-range, out-of-range  


Location Pseudo Classes:
-> used to style links and elements that are targeted within the current document
-> offer a way to apply styles based on whether a link is visited or an element is currently in focus
-> link, visited, any-link, local-link, target


Tree-Structural Pseudo Classes:
-> allow you to target and style elements based on their position within the document tree
-> document tree refers to the hierarchical structure of elements in an html document
-> root, empty, nth-child(n), nth-last-child(n), first-child, last-child, only-child, nth-of-type, 
   first-of-type, last-of-type, only-of-type

Functional Pseudo Classes:
-> allow you to select element based on more complex conditions or relationships
-> they accept arguments within parenthesis
-> is(), where(), has(), not()



Pseudo Elements:
-> virtual or synthetic elements that do not directly match any actual html elements
-> allow you to style specific parts of an element or insert content without adding extra html
-> selector::pseudo-element { property: value; }
-> before, after, first-letter, marker, placeholder, spelling-error, selection



Color Theory:
-> the study of how colors interact with each other and how they affect our perception
-> covers color relationships, color harmony, psychological impact of color
-> primary colors: red, green, blue. fundamental hues from which all other colors are derived
-> secondary colors: result from mixing equal amounts of two primary colors
-> tertiary colors: result from combining a primary color with a neighboring secondary color
-> color models: RGB, HSV, HSL
-> color wheel: a circular diagram that shows how colors relate to each other
-> color scheme: the set of colors chosen for a specific design or project
-> analogous color schemes create cohesive and soothing experiences. they have colors adjacent to each other in color wheel
-> complementary color schemes create high contrast and visual impact. their colors are located on the opposite ends of
   color wheel, relative to each other
-> color contrast ensures that text and other important elements are clearly distinguishable from their background
-> triadic color scheme has vibrant colors. they are made from colors that are approximately equidistant from each other. 
   if connected, they form an equilateral triangle on the color wheel
-> in monochromatic color scheme, all colors are derived from the same base color by adjusting its lightness, darkness 
   and saturation. it evokes a feeling of unity and harmony while creating contrast



Overflow:
-> the way elements handle content that exceeds or overflows the size of the containing element
-> two-dimensional, horizontal & vertical


Transform:
-> allows you to modify the visual presentation of elements without affecting the layout of other elements
-> enables you to apply various transformations such as rotating, scaling, skewing or translating them in 2D or 3D space
-> works by applying a mathematical transformation to an elements coordinate system
-> accessibility considerations:
  - screen reader order
  - text scaling
  - motion and depth perception
  - hiding content properly
  - target size for interactive elements



CSS Box Model:
-> defines how html elements are structured and positioned
-> every element is surrounded by a box
-> box consists of four elements: 
  - content area: innermost part of the box. space that contains the actual content
  - padding: space between the content area and the border
  - border: outer edge or outline of an element
  - margin: space outside the border of an element


Margin Collapsing:
-> a behavior that occurs when the vertical margins of adjacent elements overlap
-> resulting in a single margin equal to the larger of the two
-> the larger margin wins and determines the space between elements
-> applies only to vertical margins


Box Sizing:
-> controls how the width and height of elements are calculated
-> content-box: does not include padding, border or margin when determining the height and width (default)
-> border-box: includes padding and border (not margin) when setting width and height of an element



CSS Reset:
-> a stylesheet that removes all or some of the default formatting that the web browsers apply to html elements
-> purpose: to establish a consistent baseline for styling, reducing browser specific behaviors
-> popular third-party browser reset: Normalize.css



CSS Filter:
-> allows you to apply graphical effects elements on a web page
-> useful for adjusting the visual presentation of images, backgrounds and even text without modifying the original asset 
-> selector { filter: function(amount); }
-> some common filter functions: blur, brightness, grayscale, sepia, hue-rotate, contrast, invert, saturate
-> has the ability to combine multiple effects 
-> img { filter: contrast(150%) brightness(110%) sepia(30%); }



CSS Flexbox:
-> a one-dimensional layout model that allows you to arrange elements in rows or columns within a container
-> you can also control their order and orientation
-> two key concepts: flex container and flex item
-> some common flex properties: flex-direction, justify-content, align-items, flex-wrap
-> flex model defines how flex items are arranged within a flex container
-> every flex container has two axes: main axis, cross axis



Float:
-> a technique originally designed to allow text to wrap around an element such as an image
-> when an element is floated, it's taken out of the normal document flow and pushed to the left or right of its container
-> the content that follow will wrap around the floated element, filling the remaining space


Positioning:
-> allows to control how elements are laid out on a page
-> static: by default elements are statically positioned, following the normal flow of the document
-> relative: allows an element to be shifted from its normal position without disrupting the document flow
-> absolute: 
  - allows you to take an element out of the document flow, making it behave independently from other elements
  - placed in its own layer, completely separate from everything else in the layout
  - useful for creating floating UI features e.g. modals, tooltips, dropdown menus, which can overlap other elements
  - by default, absolutely positioned elements are placed relative to the closest positioned ancestor
  - if no positioned ancestor is found, the element will be positioned relative to the initial containing block, 
    which is usually the browser's viewport
-> fixed:
  - element is removed from the normal document flow and placed relative to the viewport
  - it stays in the same position even when the user scrolls
  - often used for elements like headers or navigation bars that need to remain visible at all times
-> sticky:
  - behaves as a hybrid between relative and fixed positioning
  - initially, the element behaves as though it's positioned relatively, staying within the document flow
  - once the user scrolls the element past a certain point, it "sticks" to the viewport (usually the top) 
    and behaves as though it is fixed
  - great for creating elements like sticky navigation bars, that become fixed once the user scrolls to a certain position



Differences between absolute, fixed and sticky positioning:
-> a positioning removes an element from the document flow and positions it relative to the nearest positioned ancestor, 
   or the initial containing block if none exists. The element stays in that position regardless of scrolling
-> fixed positioning also removes the element from the document flow but fixes it relative to the viewport, 
   meaning it will stay visible in the same spot even as the page is scrolled
-> sticky positioning keeps the element in the normal flow initially but allows it to stick in place after scrolling 
   past a defined threshold



Z-Index:
-> used to control the vertical stacking order of positioned elements that overlap on the page
-> when multiple elements are stacked on top of each other, the z-index value determines which element appears on top
-> the higher the z-index value, the closer the element is to the viewer
-> lower values place the element farther back in the stack
-> elements with higher z-index values will be placed above those with lower values
-> only works on elements that are positioned e.g. relative, absolute, fixed
-> default value is auto which places the element in the default stacking order
-> useful for controlling how overlapping elements behave in complex layouts, such as modals, pop-ups, or tooltips 



Attribute Selectors:
-> allows you to target HTML elements based on their attributes
-> it means you can apply styles to elements that have specific attributes or even certain values for those attributes
-> useful when you want to style elements dynamically or when class names alone don't provide enough specificity



Typography:
-> the art of choosing the right fonts and format to make texts visually appealing and easy to read
-> the art and technique of arranging type to communicate effectively
-> type refers to how the individual characters are designed and arranged

Typeface: 
-> overall design and style of a set of characters, numbers, and symbols
-> a font is a specific variation of a typeface with specific characteristics such as size, wight, style, and width
-> classifications: script, blackletter, monospaced, decorative
-> weight: the thickness of characters, including light, regular, bold, and black
-> style: the slant and orientation of characters like italic and oblique
-> width: the horizontal space occupied by characters like condensed and expanded



Elements of Typography:
-> Baseline: imaginary line on which most characters rest
-> Cap Height: height of the uppercase letters, measured from baseline to top
-> X-Height: average height of lowercase letters, excluding ascenders and descenders
-> Ascenders: parts of the lowercase letters that extend above the x-height 
-> Descenders: parts of the lowercase letters that extend below the baseline
-> Kerning: how space is adjusted between specific pairs of characters to improve their readability and aesthetics
-> Tracking: how space is adjusted between all characters in a block of text, essentially the distance between characters
-> Leading: vertical space between lines of text, measured from the baseline of one line to the baseline of the next line


Font Family:
-> a group of fonts that share a common design
-> all the fonts that belong to the same family are based on the same core typeface
-> but they also have variations in their style, weight, and width.

Generic Font Families:
-> a default font that web browsers will render when the higher priority fonts are not available
-> some common ones: serif, sans-serif, monospace, cursive, fantasy

Web Safe Fonts:
-> a subset of fonts that are very likely to be installed on a computer or device

Layout:
-> how the visual elements are arranged on a page or screen to communicate a message
-> it's like the blueprint of a design
-> designers consider the placement, size and hierarchy of each element

Alignment:
-> how elements are placed in relation to one another
-> designers align elements along imaginary lines, edges or a central point

Composition:
-> the art of arranging elements to create a harmonious design
-> it determines how elements like images, text and shapes relate to each other and contribute to the design in an artistic way
-> it considers the artistic impact on overall design

Balance:
-> how the visual weight is distributed within a composition
-> designers aim to create an equilibrium through symmetrical or asymmetrical arrangements

Hierarchy:
-> it establishes the order of importance of the elements in a design
-> it's about making sure the most important information is noticed first
-> you can implement a visual hierarchy with size, color, contrast, alignment, whitespace and even typography
-> guides the viewers attention in a specific order 

User Interface:
-> how humans interact with computers
-> includes visual and interactive elements that users can see on their screen

User Experience:
-> how users feel when using a product or service

Progressive Enhancement:
-> a design approach that ensures all users regardless of browser or device, can access the essential content and
   functionality of an application

User Centered Design:
-> a web development approach that prioritizes the end user, from their needs to their preferences and limitations
-> the goal is to craft a web page that is intuitive, efficient to use and pleasing for users to interact with
-> one of the first aspects is considering your target demographics
-> another aspect is consider the goal of end users
-> user behavior is an important factor, you'll want to leverage an analytics tool like google analytics
-> a key to user-centered design is to actually involve users, providing a feedback chanel

User Research:
-> systematic study of the people who use your product
-> goal is to measure user needs, behaviors and pain points
-> NPS - Net Promoter Score
-> measures how likely are users to recommend your product to a friend
-> measured through survey
-> another research vector is exit interview
-> a survey to show your users when they cancel a subscription or delete an account
-> it can give you insights into the factors causing user churn, so you can address them

User Testing:
-> the practice of capturing data from users as they interface with your application
-> a video game going through a beta testing
-> in case of web development, there is A/B testing
-> involves shipping a new feature to a randomly selected subset of your user base
-> then you can leverage analytics data to determine if the feature is beneficial

User Requirements:
-> stories or rubrics that your application needs to follow
-> might be defined by user research or industry standards or stakeholder input
-> requirements maybe functional or non-functional

Progressive Disclosure:
-> a design pattern used to only show users relevant content based on their current activity and hide the rest
-> it's done to use cognitive load and make the user-experience more intuitive

Lazy Registration:
-> a UI design pattern that allows users to browser and interact with your application without having to register
-> users need to see the value your site offers before willing to provide their information

Design Brief:
-> a document that outlines the objectives, goals and requirements of a project
-> a roadmap that guides the design process ensures that the final product meets the needs of the client
-> usually the client will write the design brief and it will serve as a working draft
-> key elements:
   - overview of the project and business
   - document the goals and objectives
   - target audience: target demographics, interests, needs
   - project scope: deliverables, timeline, budget


Vector-based Design:
-> involves creating art using mathematical formulas to define lines, shapes and colors

Prototyping:
-> the process of creating an interactive model of a product or user interface
