CSS:
-> a stylesheet language used to apply styles to html elements
-> allows to control the layout, colors, fonts and overall visual appearance of a webpage without altering the html structure
-> the primary purpose of CSS is to separate the presentation of a document from its content
-> contributes to responsive web design by allowing adjustments to layout and styling based on device screen size
-> the cascading nature of CSS means it allows styles to be inherited or overridden in a hierarchical manner

CSS Rule:
-> made up of two main parts - selector and declaration block
-> selector { poperty: value }
-> a selector is a pattern to identify and target specific html elements
-> type selector, class selector, id selector

Viewport:
-> <meta name="viewport"> gives instructions to browsers on how to control the page's dimensions and scaling on different devices
-> width=device-width tells the browser to match the page width to the device's screen width

Default Browser Styles / User-Agent Styles:
-> provides basic formatting to ensure html elements are displayed in a readable way across all browsers

Width and Height:
-> controls the dimensions of an element on a webpage
-> can be defined in px, %, vw, vh and more
-> if you do not specify the width and height, they will be set to auto
-> it lets the browser determine the element's width and height based on its content, parent and display type
-> for a div, width: auto makes it expand to fill the full width of its parent container

Pixel:
-> fixed size unit of measurement
-> provides precise control over dimension

Combinators:
-> defines the relationship between selectors
-> help select elements based on their relationship to other elements
-> allows for more precise and efficient styling
-> descendant combinator (space), child combinator (>), next-sibling combinator (+), subsequent-sibling combinator (~)

Block Elements:
-> take up the full width available to them
-> stretch across the width of their container
-> start on a new line and push other contents to the next line
-> div, p, headings, ol, ul, section
-> sizes can be controlled

Inline Elements:
-> take up as much width as they need
-> do not start on a new line
-> flow within the content
-> sizes cannot be controlled
-> span, a, img

Inline-block Elements:
-> remain in the text flow without starting on a new line
-> sizes can be adjusted

Margin:
-> controls the space outside an element
-> helps define the layout structure and separate from other elements

Padding:
-> controls the space inside an element
-> improves content readability and aesthetic appeal

Specificity:
-> determines which styles are applied to an element when rules could apply
-> calculated based on the type of selectors used
-> highest: inline style applied through style attribute
-> next, id selectors
-> next, class selectors, attribute selectors and pseudo classes
-> next, type selectors and pseudo elements

Universal Selector (*):
-> matches any element in the document
-> lowest specificity

important Keyword
-> !important
-> gives a style rule the highest priority, overriding any other declarations for a property
-> used after the css value and before the semicolon

Cascading Algorithm:
-> the process browser uses to decide which css rules to apply when there are multiple styles targeting the same element
-> ensures that most appropriate styles are used based on  a set of well defined rules
-> begins with relevance
-> then considers origin and importance
-> next looks at specificity
-> finally order of appearance comes into play

Inheritance:
-> color, font-family, line-height are inherited by default
-> margin, padding, border, background are not inherited by default
-> if you want a child element to inherit these styles, you need to use inherit keyword

Link States:
-> link, visited, hover, focus, active

Pseudo Class:
-> a keyword added to a selector that specifies a special state of that element

Background Image:
-> background-size, background-repeat, background-position, background-attachment
-> background: center top fixed url("")

Gradient:
-> a smooth transition between two or more colors
-> linear gradient and radial gradient
-> linear gradient transitions color along a straight line
-> background: linear-gradient(direction, color-stop1, color-stop2, ...)
-> linear-gradient(to right, red, yellow)
-> radial gradient transitions colors from an origin (usually the center) outward in a circular or elliptical shape
-> background: radial-gradient(shape size at position, color-stop1, color-stop2, ...)
-> radial-gradient(circle closest-side at corner, red, yellow 50%, green)

Absolute Units:
-> fixed-size unit of measurement. not relative to anything else
-> pixel (px)
-> 1 pixel = 1/96 inch
-> use when you need precise control over element dimensions, spacing, and layout

Percentages:
-> a relative unit that allow yous to define sizes, dimensions and other properties as a proportion of their parent element
-> it essentially means, make this X% of its container
-> ideal for creating fluid layouts that adapt to different screen sizes
-> using for flexible images is another common practice
-> less common but can also be used for font sizes to create scalable typography
-> particularly handy for vertical centering


em:
-> relative unit
-> relative to the font size of the element
-> if you use em for font-size property, the size of text will be relative to the font size of parent element
-> good to use when you're working with modular components like buttons or cards
-> it can ensure that all aspects of the component such as padding, margin, border scale proportionally with font size


rem:
-> unit for typography
-> relative to the font size of the root element which is html
-> by default, font size of html element is 16px
-> preferred over pixel for typography as it scales proportionally with the user's browser setting
-> can also help maintain consistent spacing and layout across different elements


vh:
-> viewport height
-> 1vh is equal to 1% of the viewport's height

vw:
-> viewport width
-> 1vw is equal to 1% of the viewport's width

# vh and vw are relative units that allow you to size elements based on the dimension of the browser window
# useful when you want to create full-screen layouts or elements that maintain a specific proportion of the screen


Layout:
-> how the visual elements are arranged on a page or screen to communicate a message
-> it's like the blueprint of a design
-> designers consider the placement, size and hierarchy of each element

Alignment:
-> how elements are placed in relation to one another
-> designers align elements along imaginary lines, edges or a central point

Composition:
-> the art of arranging elements to create a harmonious design
-> it determines how elements like images, text and shapes relate to each other and contribute to the design in an artistic way
-> it considers the artistic impact on overall design

Balance:
-> how the visual weight is distributed within a composition
-> designers aim to create an equilibrium through symmetrical or asymmetrical arrangements

Hierarchy:
-> it establishes the order of importance of the elements in a design
-> it's about making sure the most important information is noticed first
-> you can implement a visual hierarchy with size, color, contrast, alignment, whitespace and even typography
-> guides the viewers attention in a specific order 

User Interface:
-> how humans interact with computers
-> includes visual and interactive elements that users can see on their screen

User Experience:
-> how users feel when using a product or service

Progressive Enhancement:
-> a design approach that ensures all users regardless of browser or device, can access the essential content and
   functionality of an application

User Centered Design:
-> a web development approach that prioritizes the end user, from their needs to their preferences and limitations
-> the goal is to craft a web page that is intuitive, efficient to use and pleasing for users to interact with
-> one of the first aspects is considering your target demographics
-> another aspect is consider the goal of end users
-> user behavior is an important factor, you'll want to leverage an analytics tool like google analytics
-> a key to user-centered design is to actually involve users, providing a feedback chanel

User Research:
-> systematic study of the people who use your product
-> goal is to measure user needs, behaviors and pain points
-> NPS - Net Promoter Score
-> measures how likely are users to recommend your product to a friend
-> measured through survey
-> another research vector is exit interview
-> a survey to show your users when they cancel a subscription or delete an account
-> it can give you insights into the factors causing user churn, so you can address them

User Testing:
-> the practice of capturing data from users as they interface with your application
-> a video game going through a beta testing
-> in case of web development, there is A/B testing
-> involves shipping a new feature to a randomly selected subset of your user base
-> then you can leverage analytics data to determine if the feature is beneficial

User Requirements:
-> stories or rubrics that your application needs to follow
-> might be defined by user research or industry standards or stakeholder input
-> requirements maybe functional or non-functional

Progressive Disclosure:
-> a design pattern used to only show users relevant content based on their current activity and hide the rest
-> it's done to use cognitive load and make the user-experience more intuitive

Lazy Registration:
-> a UI design pattern that allows users to browser and interact with your application without having to register
-> users need to see the value your site offers before willing to provide their information

Design Brief:
-> a document that outlines the objectives, goals and requirements of a project
-> a roadmap that guides the design process ensures that the final product meets the needs of the client
-> usually the client will write the design brief and it will serve as a working draft
-> key elements:
   - overview of the project and business
   - document the goals and objectives
   - target audience: target demographics, interests, needs
   - project scope: deliverables, timeline, budget


Vector-based Design:
-> involves creating art using mathematical formulas to define lines, shapes and colors

Prototyping:
-> the process of creating an interactive model of a product or user interface
